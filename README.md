# desarrollo_web_agustin_pe-a
Trabajo de CC5002,pagina de ornitologia

La pagina se divide en 3 HTMLs uno de INICIO, donde se puede ver los avistamientos publicados, uno de VISTA que permite registrar un avistamiento y uno de REGISTRO para crear una cuenta.

Actualmente los avistamientos publicados se guardan temporalmente en el almacenamiento local, y como prueba se adjuntan 5 imagenes para probar una publicacion. Las imagenes son: un Mirlo, un Chercán, una Tortola, un Tiuque y un Zorzal.
Ya que las imagenes se guardan en almacenamiento local si es muy pesada puede dar errores, asi que se recomienda experimentar con las imagenes adjuntas.

Por temas de simplicidad se decidio que la hora del avistamiento sea opcional, pues es algo que personalmente encontre muy detallado como para pedirlo siempre, pero si hace falta se puede hacer obligatorio agregando una condicion extra al javascript que valida el form.

Por ahora no hace falta estar registrado para hacer un avistamiento.
